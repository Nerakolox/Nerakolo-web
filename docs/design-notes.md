## 当前阶段

## 视觉方向

灰色纸面、墨黑线稿、手写签名与克制的无衬线正文。保留个人介绍、社交地址、友链与备案信息。旧版 Design 以及上一轮金属雕塑方案均不作为视觉约束。

- 首屏：完整人物线稿作为大幅背景画面，英文签名作为主品牌，搭配原站中文标语。
- 关于：两栏介绍结构。左侧集中问候、宣言与中文签名，右侧用自然直接的文字介绍编程、工具、Minecraft、AI 和音乐兴趣，再接两组兴趣条目；手机端依次阅读。
- 社交：使用用户提供的书桌信笺完整画面。左侧留白内排英文标题、错位的 GitHub / Gitee 入口和独立邮件落款，右侧保留耳机、手和信纸。
- 友链：使用用户更新的无字远景，标题和两条入口错位排入天空，保留屋顶与人物背影。浅色过渡带承载区名和申请入口。
- 手机端：文字先按正常顺序阅读，完整横向原画在下方接续，不用竖屏裁切隐藏主体。
- 两个插画区域保留原画灰调和固定深墨色文字，切换深色主题时仍保持图文对比；不反转或压暗原画。
- 页脚：邮件联系与文字收尾，移除重复人物图和英文签名。
- 保留主题切换、移动导航、邮箱复制；正文采用分组的一次入场动效，默认内容可见。主题图标交替旋转淡入，菜单内容依次展开，关闭时短暂淡出；减少动态效果设置下立即切换。
- 导航保留首页高度和文档占位，滚动后内层平滑收为桌面 64px、手机 60px，底色略透明并带淡分隔线；当前阅读段落有导航指示，锚点偏移按紧凑高度计算。
- 移动菜单顶部与页面导航共用网格、边距、签名尺寸及主题按钮，打开时锁定当前高度，避免签名位移；关闭后恢复焦点，切换到桌面宽度时自动关闭。
- 图片和 SVG 禁止拖拽，保留链接点击和正文选择；图标按钮统一无底色，用图标透明度和按下反馈表示交互。
- 页面滚动条固定悬浮于右边，不占布局宽度，支持拖动、轨道点击和键盘；仍使用原生文档滚动。菜单打开时隐藏，高对比色模式回退原生滚动条。
- Favicon 使用用户提供的签名首字，裁去多余透明留白并保留原笔形。SVG 内嵌透明位图蒙版，随浏览器明暗外观切换墨黑或浅白；ICO 提供 16/32/48px 中灰后备，Apple 触屏图标使用浅灰底。
