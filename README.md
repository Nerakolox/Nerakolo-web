# Nerakolo

React + Vite frontend project using JavaScript and Oxlint.

## Development

Requires Node.js 20.19+ or 22.12+ and npm.

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

Run `npm run preview` to preview the production build locally.
